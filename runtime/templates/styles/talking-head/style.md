# Talking-Head Style

Edit from the verified transcript, but never let automatic compression change speaker meaning. A hook-first opening, take selection, filler removal, or silence compression is allowed only when the creative brief calls for it and a readable paper edit is reviewed first.

Favor clean source-linked cuts, motivated punch-ins, real B-roll, verified lower thirds, and graphics that explain a concrete idea. HyperFrames is primary; Remotion remains an optional fallback. Preserve an editable base timeline, separate graphics, captions, dialogue, music, ambience, and SFX.

Before editing, confirm the audience, platform, runtime, aspect ratios, speaker name and pronunciation, must-keep claims, exclusions, caption style, brand, call to action, and whether rearranging source chronology is allowed.
