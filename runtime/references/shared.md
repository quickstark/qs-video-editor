# Shared video contract

Use the actual loaded plugin and a user-owned workspace outside it. Read the named project's manifest, brief, local brand/style, current stage state, and approval log before sustained work. Do not choose a project because its name appears in an example.

Keep originals unchanged. Probe rather than guess timing, color, dimensions or audio layout. Preserve rational frame rates, stable source IDs, source ranges, and checksum lineage. Write new derivatives and keep reversible decisions beside them. Reuse completed stages when input hashes, parameters, tool/model identity and dependencies still match.

Ground selects and story decisions in source ID plus time span. Read transcripts/inventory first; inspect decision-critical frames and listen to uncertain dialogue. Record missing evidence explicitly. Never invent documentary facts, speaker identity, quotations or reactions. Wedding/documentary pauses and complete thoughts remain unless the brief permits compression.

Local reversible work necessary for the requested task is authorized. Reuse approvals within their recorded action, material/revision, destination and cost scope. Obtain missing authorization for uploads, hosted/paid generation, installs, publishing, destructive cleanup, or replacing approved deliverables. A helper's --apply flag is a write gate, not a requirement to ask the user twice. Prepare the concrete result before requesting a required review decision.

Report technical, visual/motion, listening, editorial/privacy, and editor-import checks separately. Still frames do not establish motion or audio review. Preserve composition source, separate tracks/stems/captions, relink maps, and the neutral timeline. Claim DRP/DRT only after a real Resolve export and import check; otherwise identify the portable handoff accurately.

Use the workspace-bound launcher. Missing optional capabilities block their own stages only. Inspect plan output before applying; never bypass a stale hash, checksum mismatch, output conflict, or unknown schema. Record exact commands and tool versions. No private media, model cache, credentials, dependency directories or real project state belongs in the plugin package.
